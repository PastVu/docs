# Проекты, использующие API PastVu

Некоторые сторонние проекты используют [PastVu API](../dev/api). Если вы знаете ещё один или создали его сами, пожалуйста, пришлите PR, чтобы добавить его в этот документ.

<!-- cspell:ignore Geometki -->

- Мобильное приложение PastVu с [открытым исходным кодом](https://github.com/pelixpng/PastVuApp). Доступно в [App Store](https://apps.apple.com/app/pastvu-com/id6482482875) и [Google Play](https://play.google.com/store/apps/details?id=com.pelixpng.PastVuApp).
- Мобильное приложение PastVu Map. Доступно в [App Store](https://apps.apple.com/app/pastvu-com/id6499492010).
- [Rewind](https://github.com/chizberg/Rewind) — нативное iOS-приложение, [доступное в App Store](https://apps.apple.com/app/rewind-history-on-a-map/id6755358800). Исходный код [версии для Android](https://github.com/chizberg/Rewind-android) также открыт.
- [History Lens](https://github.com/ALabrada/time_machine) — мобильное приложение для поиска исторических фотографий поблизости и сравнения прошлого с настоящим. PastVu используется как один из источников данных. Доступно в [RuStore](https://www.rustore.ru/catalog/app/com.fakegem.historylens).
- [PastViewer](https://github.com/malicioushair/pastviewer) — приложение с открытым исходным кодом для просмотра исторических фотографий на карте и воссоздания запечатлённых видов. Доступно в [App Store](https://apps.apple.com/rs/app/pastviewer/id6761183383) и [Google Play](https://play.google.com/store/apps/details?id=org.qtproject.PastViewer).
- [Geometki](https://geometki.com) — народная карта интересных мест России со слоем исторических фотографий PastVu ([исходный код](https://github.com/miksrv/geometki)).
- [Notimaps](https://notimaps.com) — сервис фильтрации информации на основе геоданных, использующий PastVu как один из источников обновлений на карте ([пример](https://notimaps.com/map/55.750745/37.610398/12.79/661799623d3cd21b409c3e6a/)).
- [retromap.ru](https://retromap.ru) показывает фотографии PastVu с привязкой к старинным картам.
- [@PastvuBot](https://t.me/PastvuBot) — Telegram-бот, который отправляет исторические фотографии PastVu для запрашиваемого местоположения ([исходный код](https://github.com/ratmirslv/pastvu-bot)).
- [Godina](https://rastereo.github.io/godina) — игра «Угадай год по фотографии», использующая PastVu как один из источников изображений ([исходный код](https://github.com/rastereo/godina)).
- [PastVu gem](https://github.com/projecteurlumiere/pastvu) — библиотека на Ruby для удобного взаимодействия с PastVu API.
