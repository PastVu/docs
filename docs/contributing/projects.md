# Projects that use PastVu API

Several third-party projects use the [PastVu API](../dev/api). If you know of
another project or have created one yourself, please submit a PR to add it to this document.

:::info
Most of the listed projects are not localised. Consider contacting the authors of open source projects if you can help with translation.
:::

<!-- cspell:ignore Geometki -->

- PastVu mobile application ([open source code](https://github.com/pelixpng/PastVuApp)). Available on the [App Store](https://apps.apple.com/app/pastvu-com/id6482482875) and [Google Play](https://play.google.com/store/apps/details?id=com.pelixpng.PastVuApp).
- PastVu Map mobile application. Available on the [App Store](https://apps.apple.com/app/pastvu-com/id6499492010).
- [Rewind](https://github.com/chizberg/Rewind) is a native iOS application [available on the App Store](https://apps.apple.com/app/rewind-history-on-a-map/id6755358800). An open source [Android version](https://github.com/chizberg/Rewind-android) is also available.
- [History Lens](https://github.com/ALabrada/time_machine) is a mobile application for finding nearby historical photos and comparing past and present views. PastVu is one of its data sources. Available on [RuStore](https://www.rustore.ru/catalog/app/com.fakegem.historylens).
- [PastViewer](https://github.com/malicioushair/pastviewer) is an open source application for exploring historical photos on a map and recreating their views. Available on the [App Store](https://apps.apple.com/rs/app/pastviewer/id6761183383) and [Google Play](https://play.google.com/store/apps/details?id=org.qtproject.PastViewer).
- [Geometki](https://geometki.com) is a crowdsourced map of places in Russia with a layer of historical PastVu photos ([source code](https://github.com/miksrv/geometki)).
- [Notimaps](https://notimaps.com) is a geolocation-based information filtering service that offers PastVu as a source of map updates ([example](https://notimaps.com/map/55.750745/37.610398/12.79/661799623d3cd21b409c3e6a/)).
- [retromap.ru](https://retromap.ru) displays PastVu photos on old maps.
- [@PastvuBot](https://t.me/PastvuBot) is a Telegram bot that sends PastVu historical photos for a requested location ([source code](https://github.com/ratmirslv/pastvu-bot)).
- [Godina](https://rastereo.github.io/godina) is a photo year-guessing game that uses PastVu as one of its image sources ([source code](https://github.com/rastereo/godina)).
- [PastVu gem](https://github.com/projecteurlumiere/pastvu) is a Ruby wrapper for convenient interaction with the PastVu API.
